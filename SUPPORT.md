# Support

Use the [GitHub issue tracker](https://github.com/willibrandon/vscode-systemd/issues) for
reproducible bugs and focused feature requests. Search existing issues first.

Include:

- extension and VS Code versions;
- desktop, remote, or browser extension host;
- the detected language ID;
- target systemd, Podman, or mkosi version;
- a minimal redacted configuration;
- built-in diagnostic codes and, when relevant, installed-validator output.

Never attach production configuration, credentials, private paths, or unredacted account names.
Questions about systemd behavior itself belong in the
[systemd project](https://github.com/systemd/systemd). Security reports must follow
[SECURITY.md](SECURITY.md).
